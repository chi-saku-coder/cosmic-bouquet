# research — SNS リサーチスキル

占いジャンルの SNS 投稿動向を調査し、コンテンツ戦略の材料を集める。
実行前に必ず `CLAUDE.md` のブランド文脈を読み込むこと。

---

## トリガー

「リサーチして」「どんな投稿が伸びてるか調べて」「競合を調べて」「ネタ探して」と言われたとき。

---

## 調査対象ジャンル

コズミック・ブーケのサービスに近いジャンルを優先して調査する。

```
優先度 高
  - マヤ暦（キン番号・ウェイブスペル・13の月の暦）
  - 名前鑑定（名前の周波数・音霊・数秘）
  - ホロスコープ・占星術（ネイタルチャート・星座の特性）

参考として調査
  - 数秘術（ライフパスナンバー）
  - カード占い（タロット・オラクル）
  - 四柱推命・九星気学
```

---

## 実行手順

### STEP 1　プラットフォームと調査目的の確認

以下が指定されていない場合はユーザーに確認する。

```
【調査プラットフォーム】（複数可）
  □ X（Twitter）
  □ note
  □ Instagram

【調査目的】
  A. どんなコンテンツが存在するか（ジャンルマップ把握）
  B. 何が反応を得ているか（エンゲージメント分析）
  C. ハッシュタグの使われ方（タグ戦略）
  D. 競合アカウントの投稿パターン
```

---

### STEP 2　調査の実施

#### A. ジャンルマップ把握

以下のキーワードで投稿を検索・収集する：

```
マヤ暦 / マヤ暦鑑定 / キン番号 / ウェイブスペル
名前鑑定 / 名前の周波数 / 音霊鑑定
ホロスコープ鑑定 / 占星術鑑定 / ネイタルチャート
完全鑑定 / 自己理解 / 魂のテーマ
```

収集する情報：
- 投稿のテーマ分類（教育系 / 体験談 / 告知 / 日常 / 問いかけ）
- 文体のトーン（です・ます / ゆるい / 詩的 / 解説系）
- 画像・デザインの特徴
- CTA の有無と種類

#### B. エンゲージメント分析

反応の多い投稿に共通する要素を探す：

```
確認する指標：
  X   → いいね数・RT 数・リプライの内容
  note → スキ数・コメント・ビュー数（公開されている場合）
  Instagram → いいね数・保存数・コメント

注目するポイント：
  - タイトル・つかみの言葉の傾向
  - 長さ（短文 vs 長文）
  - 画像あり vs テキストのみ
  - 投稿時間帯（わかる場合）
```

#### C. ハッシュタグ調査

```
調査するタグ：
  #マヤ暦 #マヤ暦鑑定 #キン番号 #名前鑑定 #ホロスコープ鑑定
  #占星術 #自己理解 #魂のテーマ #スピリチュアル #完全鑑定書

各タグについて確認：
  - 投稿数の規模（多すぎると埋もれる / 少なすぎると届かない）
  - どんな投稿が上位に来ているか
  - 一緒に使われやすいタグの組み合わせ
```

#### D. 競合アカウント調査

```
マヤ暦・名前鑑定・ホロスコープ鑑定を組み合わせているアカウントを探す。

確認項目：
  - フォロワー数・エンゲージメント率
  - 投稿頻度・曜日パターン
  - コンテンツの柱（何を中心に発信しているか）
  - 差別化ポイント（自分との違い）
```

---

### STEP 3　発見をまとめる

以下の形式で整理する：

```
【ジャンル全体の傾向】
- 多い投稿タイプ：
- 少ない投稿タイプ（空白地帯）：
- よく使われる言葉・表現：
- 避けられている表現：

【反応が取れている投稿の特徴】
- 共通するつかみの言葉：
- 文体・長さ：
- 画像の傾向：
- CTA のパターン：

【ハッシュタグ推奨セット】
- X 用（5個）：
- Instagram 用（10〜15個）：

【コズミック・ブーケへの示唆】
- 取り入れられそうな要素：
- 差別化できるポイント：
- 避けた方がいい方向性：
```

---

### STEP 4　atoms.csv に記録する

発見したコンテンツの種を `data/atoms.csv` に追記する。

```
記録フォーマット：
  id, 日付, ジャンル, コンテンツテーマ, 参考にした投稿の特徴, メモ, 優先度（高/中/低）
```

---

## 調査の注意事項

- 特定アカウントの文章をそのままコピーしない
- 「こういう傾向がある」という分析にとどめ、盗用にならないようにする
- 反応が多い ≠ コズミック・ブーケに合う、と判断する（ブランドトーンと照合する）
