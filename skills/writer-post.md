# writer-post — SNS 投稿生成スキル

コズミック・ブーケの SNS 投稿文を生成する。
実行前に必ず `CLAUDE.md` のブランド文脈を読み込むこと。

---

## トリガー

「投稿作って」「SNS 用の文章を生成して」「〇〇の告知を投稿にして」「お客様の声を投稿にして」と言われたとき。

---

## 実行前に確認する情報

以下が揃っていない場合はユーザーに聞いてから進む。

```
【投稿タイプ】
  A. 鑑定書の告知・PR
  B. お客様の声・体験談

【プラットフォーム】（複数選択可）
  □ X（Twitter）
  □ note
  □ Instagram

【素材】
  A の場合 → 何を伝えたいか（受付開始 / 締切 / 内容説明 / キャンペーン など）
  B の場合 → お客様の声の原文（data/voices.csv から掲載許可○のもの）
```

---

## 実行手順

### STEP 1　ブランド文脈の読み込み
CLAUDE.md の「ブランドトーン」「NG 表現」「OK 表現」を確認する。

### STEP 2　投稿文の生成

---

#### X（Twitter）

| 項目 | 仕様 |
|---|---|
| 本文 | 140 字以内 |
| 絵文字 | 各段落先頭に 1 個まで |
| ハッシュタグ | 5 個以内、末尾にまとめる |
| パターン数 | **3 案** |

**A. 告知・PR の構成**
```
[つかみ 1 行：問いかけ or 共感]
[サービスの価値を 2〜3 行]
[CTA（申込・詳細へ）]
[ハッシュタグ]
```

**B. お客様の声の構成**
```
[お客様の言葉を引用（短く抜粋）]
[変化・気づきを 1〜2 行で補足]
[サービス名 or CTA（任意）]
[ハッシュタグ]
```

---

#### note

| 項目 | 仕様 |
|---|---|
| 文字数 | 600〜900 字 |
| パターン数 | **2 案** |

**A. 告知・PR の構成**
```
タイトル（読みたくなるもの）
↓
導入：ターゲットへの共感（「こんなとき、ありませんか？」）
↓
本文：なぜこのサービスが必要か → 鑑定書の内容紹介
↓
まとめ：読者へのメッセージ
↓
CTA：申込フォームへ誘導
```

**B. お客様の声の構成**
```
タイトル（体験談ベース）
↓
導入：お客様のビフォー状態（共感できる悩み）
↓
本文：鑑定書で何を知ったか → どう変わったか（お客様の言葉を中心に）
↓
まとめ：読者へのひとこと
↓
CTA（任意）
```

---

#### Instagram

| 項目 | 仕様 |
|---|---|
| キャプション | 300〜500 字 |
| ハッシュタグ | 10〜15 個、本文と 1 行空けて末尾 |
| 画像提案 | alt テキスト（雰囲気の説明）を 1 行 |
| パターン数 | **2 案** |

**A. 告知・PR の構成**
```
[つかみ 1 行（改行で視線を止める）]

[サービスの価値 3〜4 行]

[CTA]

#ハッシュタグ
```

**B. お客様の声の構成**
```
[お客様の言葉を引用（" " で囲む）]

[背景・変化の補足 2〜3 行]

[サービスへの橋渡し（任意）]

#ハッシュタグ
```

**推奨ハッシュタグ（必要に応じて選択）**
```
#占星術 #ホロスコープ #名前鑑定 #自己理解 #コズミックブーケ
#完全鑑定書 #星読み #数秘術 #スピリチュアル #宇宙
#自分探し #魂のテーマ #インナーワーク #星と名前 #鑑定書
```

---

### STEP 3　品質チェック（出力前に必ず確認）

- [ ] NG 表現が含まれていないか（断定・不安煽り・過剰スピリチュアル）
- [ ] CTA が 2 箇所以上になっていないか
- [ ] ブランドトーン（温かみ・神秘的・押しつけない）が保たれているか
- [ ] 掲載許可のないお客様の声を使っていないか

---

## 出力フォーマット

各パターンを以下の形式で出力する（そのままコピペできるように）：

```
━━━━━━━━━━━━━━━━━━━━
【X 案 1】
━━━━━━━━━━━━━━━━━━━━
（投稿文）

━━━━━━━━━━━━━━━━━━━━
【X 案 2】
━━━━━━━━━━━━━━━━━━━━
（投稿文）

... （以下同様）
```

出力の最後に「改善メモ」として、より効果的にするための一言アドバイスを付ける。

---

## 使用例

```
「月が魚座に入るタイミングで鑑定書の告知投稿を X と Instagram で作って」

「data/voices.csv の ID:003 のお客様の声を 3 プラットフォーム全部の投稿にして」
```
