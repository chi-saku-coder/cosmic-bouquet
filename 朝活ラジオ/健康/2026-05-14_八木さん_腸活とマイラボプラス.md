# 腸活・マイクロバイオーム検査とマイラボプラス

## なぜ医者は食事をあまり教えてくれないのか
- 医学部の栄養学の授業は **1〜2時間のみ**（日米共通）
- 内容は欠乏症（ビタミンC不足 → 壊血病など）が中心
- 医師の役割は「マイナスをゼロに戻す」こと → 予防には時間をかけられない

---

## 医学の歴史的転換点

### 20世紀の医学の進歩
- 抗生物質の発見 → 感染症で命を落とさなくなった
- ワクチン → 予防医学の発達
- 手術技術の向上・医薬品による症状コントロール

### 1977年 マクガバンレポート
- アメリカ上院議員マクガバン氏が **食生活と慢性疾患の因果関係を国家レベルで科学的に指摘**
- 摂取を**増やす**もの：野菜・果物・全粒穀物・食物繊維
- 摂取を**減らす**もの：砂糖・脂質
- ※この時点では医学界の主流は変わらず、薬物療法中心が続いた

### 現在の問題
- 慢性疾患がどんどん増加（糖尿病：4人に1人、高血圧：30代以上男性の2人に1人）
- 病院を増やしても慢性疾患は減らない
- 超加工食品時代に突入 → 精製糖・精製炭水化物・添加物増加・食物繊維不足が加速

### 2025年 アメリカの方向転換
- 医学教育の刷新：栄養学の授業が **1〜2時間 → 40〜50時間** へ
- 「フード・アズ・メディスン（食べ物を薬として）」の考え方を導入
- 野菜・果物を薬として処方する概念が登場
- 予防医学に力を入れることで医療費削減・疾患減少を目指す

---

## 日本の医療費問題

### 社会構造の変化
- 社会保障費：**約50兆円**（税収の大部分）
- 超高齢社会・少子化（東京都が少子化ワースト1位、宮城県2位）
- 現役世代の減少 → 負担増が避けられない

### 個人負担の増加リスク
- 窓口負担額の増加（現在3割 → さらに引き上げの議論）
- 保険料上昇による手取り収入の実質的な減少
- 高額療養費制度の上限引き上げ
- OTC化（市販薬化）による一部薬の保険適用外化

> 実例：子供が入院した際、実際にかかった費用は **120万円**、窓口負担は **約3万円**（制度のおかげ）。この制度の見直しが避けられない状況。

### 結論
> **「病気になった後に全部守ってもらえる時代ではなくなりつつある」**
> → 自己責任・自己管理が当たり前の時代へ

## 病気で失うもの

### お金だけではない

| 失うもの | 内容 |
|----------|------|
| **時間** | 健康寿命と平均寿命の差（女性12年・男性10年）。本来楽しむための時間が病気対応に変わる |
| **大切な人の時間** | 介護・看病による家族の時間も奪う |
| **メンタル** | 腸内環境の悪化が脳に影響（腸脳相関）→ うつ・不安が増加 |
| **パフォーマンス** | 血糖値の乱れ → 集中力低下・仕事の質低下 |
| **人間関係** | 体調不良 → 人に優しくできない → 関係が崩れる |
| **経済** | 労働不能・パフォーマンス低下による収入減 |

> J・アンデル（Amway創設者）の言葉：**「自由とは手を振り回せること。しかし相手の自由を侵害したらそれは自由ではない。自分の病気は必ず身近な人の自由を奪う。」**

### 治療ではなく投資へ
- 病気になってからお金を払う = **コスト（損失）**
- 健康なうちに投資する = **資産形成**
- 最も利回りの良い戦略 = **健康投資**

## 健康投資の具体的な内容

1. 質の高い食事（体と心の材料）
2. 睡眠の質・量を上げる
3. 腸内環境を整える（免疫・メンタルの土台）
4. 定期的な運動

## 第2部：健康栄養学の新常識

### 「何を足すか」ではなく「どのスイッチを入れるか」
- 遺伝子は生まれた時から変わらない
- しかし **遺伝子の使い方（発現）で人生・病気・健康が変わる**
- これを **エピジェネティクス** という
- 双子でDNAが同じなのに人生・健康状態が変わるのはこれが原因

### エピジェネティクスに影響するもの
- 食事・運動・睡眠・ストレス・**腸内環境**

---

## 腸内環境の重要性

### 腸が影響する領域
- 免疫（体の7割の免疫が腸内に存在）
- メンタル（腸脳相関）
- 皮膚
- 代謝・体型
- 認知機能

### 研究事例

**体型と腸内細菌（マウス実験）**
- 同じ食事・同じカロリーでも腸内細菌層が違うと体型が変わる
- 「肥満の腸内細菌」を移植 → そのマウスも肥満に
- 「痩せの腸内細菌」を移植 → 体型が変わらない
- 代謝の低下 = 加齢ではなく、腸内細菌バランスの崩れかもしれない

**大腸癌と腸内細菌**
- 爬虫類・両生類は大腸癌にならない
- 大腸癌マウスに癌にならない動物の腸内細菌を移植 → **3日間で癌が100%消えた**（半年前の研究）

**アレルギーと腸内環境**
- 急に花粉症になった = 花粉が原因ではなく、免疫の暴走を止められなくなった体の問題
- 免疫のブレーキ（Tレグ細胞）をコントロールするのが**短鎖脂肪酸**
- 腸内環境のトラブル → ブレーキが効かない → アレルギー発症

**睡眠と食物繊維（2016年・2025年研究）**
- 食物繊維摂取量が多いほど、深い睡眠（デルタ波睡眠）が増加、中途覚醒が減少
- 同じ人で比較：野菜・果物を食べた日の方が夜中の覚醒が少ない
- **野菜を食べると腸内細菌が脳に「眠れ」と信号を送っている**

**物忘れ・認知機能（スタンフォード大学）**
- 若いマウスに老いたマウスの腸内細菌を移植 → 認知機能が著しく低下
- 老いたマウスに若いマウスの腸内細菌を移植 → 認知機能が上昇
- **犯人は腸だった**
- 現在60歳以上の5人に1人が認知症、5人に1人が認知症予備軍
- ノートレ（脳トレ）より**腸トレ**が重要

**長寿研究**
- 今日（沖縄）の高齢者の腸内フローラを調査 → 短鎖脂肪酸産生菌が多かった
- ブルーゾーン研究：健康長寿の地域は特別な遺伝子ではなく**食事・生活・人の繋がり・腸内環境**が要因
- 遺伝より生活習慣の影響の方が大きい

**楽酸とミトコンドリア（最新論文）**
- ミトコンドリア機能不全マウスに楽酸を投与 → **生存期間・健康寿命・運動能力・代謝がすべて向上**
- 楽酸（短鎖脂肪酸の一種）がミトコンドリアのエネルギー産生を助け、炎症を抑える

## Amwayの腸内研究への取り組み

- かつてDNA解析会社「インターロイキンジェネティクス」を買収
- ヒトゲノムプロジェクトに参画し、遺伝子解析を推進
- 調査の結果、**健康・疾患の主因は遺伝子ではなく腸内環境**だと先に判明
- その後、腸内細菌研究に投資 → **HM Pharma**への投資へ

## 短鎖脂肪酸ができるまで（リレーの例え）

食物繊維を食べてから楽酸が出るまでには**複数の菌が連鎖して働く**必要がある：

1. 食物繊維を分解する菌
2. 分解物を食べる菌
3. そこからやっと短鎖脂肪酸が産生される

→ アンカー（楽酸菌）だけいてもバトンが回ってこない  
→ **多様性**こそが重要

### なぜ楽酸をそのまま飲めばいいわけではないか
- 口から楽酸を入れても胃で壊れて大腸まで届かない
- 楽酸菌を入れても胃で死滅する
- 必要なのは**菌が産生できる環境（腸内環境の多様性）**

## 腸内フローラ検査 vs マイクロバイオーム検査

| 項目 | 腸内フローラ検査（一般） | マイクロバイオーム検査（マイラボプラス） |
|------|--------------------------|------------------------------------------|
| 調べること | どんな菌がどのバランスでいるか | 菌のバランス＋体への影響（代謝物） |
| 短鎖脂肪酸の測定 | ❌ | ✅ |
| 多様性 | ✅ | ✅ |
| 個別戦略 | △ | ✅ |
| 特許 | なし | 20年間（残り約18年） |

## マイラボプラスの検査内容

### 検査方法
1. 専用シートをトイレに貼って便を採取（2回）
2. 1個目：腸内細菌層（多様性）の分析
3. 2個目：短鎖脂肪酸などの代謝物分析
4. 保存液と混ぜてポストに投函

### 検査で分かること
- **総合点数**（多様性のスコア）※腸内環境の総得点ではない
- **腸内フローラタイプ**（例：スリープ型 = 多様性は高いが短鎖脂肪酸が少ない）
- 代表菌トップ5
- 入酸菌・ビフィズス菌の年代別比較（→ 腸年齢の目安）
- 悪玉菌（バクテロイデス・フラジリス）の検出
- 代謝：コレステロール・体脂肪・免疫・認知機能・睡眠・ストレス・皮膚・筋肉
- **短鎖脂肪酸バランス**（楽酸の割合など）
- 消化機能（炭水化物・タンパク質）
- ビタミンECに関わる菌

### 見方の注意点
- ビフィズス菌の順位に一喜一憂しない → **多様性バランス全体が重要**
- バクテロイデス・フラジリスは健康な人にも存在 → 多様性と短鎖脂肪酸がしっかりしていれば問題なし
- 検査結果は「原因」ではなく「普段の食生活の結果」
